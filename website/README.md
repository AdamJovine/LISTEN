# LISTEN project page

Published at https://adamjovine.github.io/LISTEN/ from this directory by `.github/workflows/pages.yml`. No framework, dependencies, or build step are needed.

Edit `index.html` to change the page. To add a talk, place its PDF under `website/slides/` and link to it using a relative URL such as `slides/ijcai-2026.pdf`. Push changes to `main`; the Pages workflow publishes them automatically. Keep slide decks in ordinary Git, not Git LFS, so GitHub Pages serves the PDFs directly.

`slides/ijcai-2026.pdf` is the 11-page talk compiled from `ijcai26/ijcai_slides.tex` in the current `Downloads/LISTEN_paper.zip` supplied by the author. It includes three backup slides. The paper PDF is linked separately through arXiv.

`slides/informs-2026.key` is the original `INFORMS_2026_LISTEN_updated (1) 2.key` supplied from `LISTEN-flights-crowd` on November 4, 2026 (SHA-256: `18b952d81e08e00996157c9926012083c3b37b301d8f8538a567857c36c4de30`). `slides/informs-2026.pdf` is its Keynote PDF export, with one page per visible slide and without presenter notes or comments. The Keynote download preserves the editable presentation and its animations.
